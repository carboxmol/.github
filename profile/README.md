## 🏛️ About CarboxMol
**CarboxMol** is a next-generation, cross-platform macromolecular crystallography workbench and interactive 3D molecular graphics studio. It is designed to work in synergy with the **Carbox** scientific core library.

### 🌟 Featured Repositories
- 🌐 **[carboxmol.github.io](https://github.com/carboxmol/carboxmol.github.io):** The live, instant-launch WebApp Studio at **[https://carboxmol.github.io](https://carboxmol.github.io)** with full offline PWA capabilities.
- 💻 **[carboxmol](https://github.com/carboxmol/carboxmol):** Complete crystallographic workbench, CLI tool,  macro automation, Python/Qt GUI, workstation server, and documentation.

### 🚀 Key Features
- **Real-Time Electron Density Contouring:** \mathrm{m}F_o - D F_c$ and $\mathrm{m}F_o - D F_c$ difference maps directly in the browser via WebGL.
- **Universal Multi-Device Responsiveness:** Adapts seamlessly across Phone, Tablet, PC, and TV.
- **Trilingual Parity:** Fully localized in English, Azerbaijani, and Hebrew (with RTL support).
- **Offline PWA:** Installable as a native app on macOS, Linux, Windows, iPadOS, and Android.
